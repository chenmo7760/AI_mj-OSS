# Sheet Rules

- Prefer clean reference-sheet composition: full body, head close-up, and optional side/back view.
- For recurring characters, prefer a complete reference sheet: front full body, three-quarter view, side view, back view, head close-up, and a small expression set when the provider can handle it.
- Build and review separate locked references per `style_profile_id` when a character must support both motion-comic and live-action realism.
- Use plain background or very simple studio background.
- No text labels, watermark, logos, captions, or extra characters.
