Required reference sheet views:

1. Front full-body neutral stance.
2. Three-quarter full-body neutral stance.
3. Side full-body neutral stance.
4. Back full-body neutral stance.
5. Head close-up with clear hairline, facial features, and accessories.
6. Expression strip with neutral, concerned, surprised, angry, and restrained smile.
7. Costume anchor view for each required costume set.

The sheet should use a clean plain background, consistent proportions, consistent costume colors, and no extra characters.
