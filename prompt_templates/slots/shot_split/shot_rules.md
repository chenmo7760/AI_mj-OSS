# Shot Rules

- Use stable shot IDs like `ep01_s001`.
- Keep one primary action or emotional beat per shot.
- Use 3-6 seconds for high-control short video shots unless the project specifies otherwise.
- Include title, location, time, atmosphere, action, result, scene, characters, character_ids, camera, shot_type, angle, movement, composition_guide, focal_point, depth_of_field, sound_design, music_cue, and transition.
- Use character `visual_hint` when visible characters are named.
