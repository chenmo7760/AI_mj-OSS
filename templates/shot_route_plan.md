## Route Rules

- `text-only`: only for low-risk shots or early draft tests.
- `reference-image`: use when character/scene/prop references exist but no locked first frame.
- `first-frame`: use when start frame is reliable and end state can be prompt-controlled.
- `first-last`: use when continuity or action result must be locked.
- `nine-grid`: use to explore framing, first/last frames, or references before selecting/cropping cells.
